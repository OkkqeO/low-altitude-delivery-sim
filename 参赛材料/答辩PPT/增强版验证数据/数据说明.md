# 补充验证数据

- `runtime_raw.csv`：30、60、120单各3次计时，共9次。按每档总耗时中位数展示。
- `route_ablation_raw.csv`：80组相同起终点在λ=0和λ=2下的航路长度和沿线暴露积分。
- `case_before_scene.json`、`case_after_scene.json`及两个同名结果目录：标准园区仅修改B1高度的对照。
- `image_case_scene.json`、`image_case/`：图片导入、定标、手动填写楼高、拖动S1后的同一场景，保存并重读计算的结果。
- `image_case_playback.csv`：图片案例在4个仿真时刻、5架无人机的20条位置与状态插值记录。
- `evidence_summary.json`：汇总指标、环境和5类异常反馈。
- `manifest.json`：程序源文件及实验结果文件的SHA256值。

在项目根目录执行：

```powershell
python "参赛材料/答辩PPT/增强版验证数据/补充实验复现.py"
```

该脚本重新生成耗时、标准园区楼高对照、航路权重对照与异常案例，写入独立的`复现实验输出/`目录，不覆盖本次PPT引用的数据。耗时受设备和后台负载影响。

图片案例可直接使用`image_case_scene.json`导入程序，保持正常配送、30单、5架无人机、巡航45米、风险权重2、评价种子20261015、错峰开启。几何和楼高已保存，手动楼高为演示值。
