00 / 系统介绍 / 0.00–8.33 秒

园区低空配送，如何兼顾时效与风险？通过地图建模、调度仿真和方案比较，为起降场选址提供依据。

01 / 问题现场 / 8.33–24.17 秒

先看仿真中的一次无人机险情。两架无人机在空中逐渐靠近，间距低于设定阈值，触发红色预警。接下来从地图输入开始，修改条件、重新计算，再回到同一时刻，检查调度是否改变了结果。

02 / 导入与定标 / 24.17–41.33 秒

点击导入地图，打开一张园区平面图。系统识别建筑候选轮廓，随后需要确认尺度并核实组件。这里输入整张图对应的九百六十米宽度，确认定标后，平面组件按比例调整，坐标和距离统一换算为米。

03 / 补齐楼高 / 41.33–56.80 秒

平面图缺少可靠的楼高信息。先批量填入三十二米，再选中一栋建筑改为五十二米。本例使用示例楼高，实际应用需要逐栋核实。地图尺度和楼高均确认后，系统才允许继续计算。

04 / 位置编辑 / 56.80–73.17 秒

选中一个候选场站，直接拖到新位置，坐标随之变化。点击撤销，点位回到原处，再重新调整。这样可以在同一张地图上修改设施条件。保存独立地图文件，原始底图和可编辑组件会一起保留。

05 / 应用地图 / 73.17–90.70 秒

点击应用并计算，编辑窗口关闭，主界面开始计算。这里展示的是刚才修改过的图片地图，候选场站数量和选址范围也随输入改变。计算完成后，地图、选中场站、航路和指标同步更新，接着可以直接播放。

06 / 固定比较条件 / 90.70–107.97 秒

下面采用标准园区进行受控比较，后续实验数据均来自这一场景。保持三十单、五架无人机、四十五米高度和风险权重二，评价种子为二零二六一零一五，间距阈值二十米。两次运行仅切换错峰设置。

07 / 基线运行 / 107.97–126.30 秒

先关闭多机错峰起飞。参数修改后，旧结果进入待计算状态，必须重新计算才能播放和导出。基线算完，点击播放，地图上的无人机、时间轴和已送达订单数持续变化。本次综合风险布局，全程检测到五次间距不足。

08 / 定位事件 / 126.30–145.27 秒

拖动时间轴到两百二十五秒附近，观察这一段接近过程。约两百三十四秒，返回中的无人机接近正在配送悬停的无人机，出现红色标记。本段事件的最小间距约零点七一米，低于二十米阈值，属于模型判定的间距不足。

09 / 修改调度 / 145.27–164.70 秒

现在开启错峰，再点击计算。计算时沿用同一张地图、同一批订单和机队参数，只改变调度开关。错峰会重新安排任务分配与运行时序。计算完成后，本次综合风险布局的全程间距不足由五次降为零。统计覆盖完整配送过程。

10 / 同刻复核 / 164.70–182.00 秒

将两种调度方案放在同一仿真时刻比较。左侧是基线，右侧是错峰。观察红色标记出现和消失的过程，以及两侧无人机位置的差异。错峰改变了任务分配与运行时序，在本次运行中避免了间距不足。

11 / 检查代价 / 182.00–201.00 秒

减少接近并不代表所有指标都更好。本次平均配送从一百零八点九一秒变为一百一十点零六秒，增加约一点一五秒，路径暴露也略有增加。两次都完成全部订单，准时率均为百分之百。这些数字只对应当前这组实验。

12 / 切换布局 / 201.00–219.43 秒

接着保持错峰设置，打开布局下拉框，先选距离优先，再选综合风险。选中场站从三号加七号变为二号加六号，地图上的场站、航路和顶部指标一起更新。两种方案共用风险加权航路规划，区别在于场站评分目标。

13 / 图层与比较 / 219.43–238.20 秒

关闭航路图层，可以看清建筑和设施；重新打开，再切换人员暴露图层，观察航路与高暴露区域的位置关系。随后打开方案对比页，在同一组评价订单下检查时效、暴露、间距不足和完成率，综合比较各方案的运行表现。

14 / 导出结果 / 238.20–255.47 秒

确认当前方案后，点击导出结果，将结果保存到指定目录。导出内容包括结果数据、订单明细和对比图表，状态栏显示导出完成。各项指标和订单记录一并保留，可用于方案复核、问题追踪和后续分析。

15 / 核对文件 / 255.47–274.23 秒

使用外部只读查看器，打开导出的结果文件。核对评价种子、错峰开关和三种方案的统计指标，再查看订单明细。任务时间、起飞时间和等待信息都保存在文件中，可以定位具体订单，分析配送时间与调度等待的关系。

16 / 适用边界 / 274.23–292.80 秒

通过地图编辑、方案计算和回放比较，可以检验输入条件与调度设置对配送结果的影响。系统采用固定高度和理想运动模型，人员暴露为代理指标。实际应用前，需要结合现场数据核实模型参数，并重新评价方案。

18 / 输出与复核 / 292.80–296.87 秒

导出结果数据、订单明细和图表，供后续复核与分析。
