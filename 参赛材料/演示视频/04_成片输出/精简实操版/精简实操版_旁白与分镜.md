00 / 系统介绍 / 0.00–5.00 秒

低空配送，如何兼顾时效与风险？用仿真比较调度与选址方案。

01 / 问题现场 / 5.00–17.47 秒

先看仿真中的一次无人机险情。两架无人机逐渐靠近，间距低于设定阈值，触发红色预警。接下来修改输入和调度，再回到同一时刻，检验运行结果。

02 / 导入与定标 / 17.47–29.10 秒

导入园区平面图，系统识别建筑候选轮廓。输入九百六十米的实际宽度，确认定标，组件坐标和距离统一换算为米，随后核实建筑与设施。

03 / 补齐楼高 / 29.10–40.50 秒

楼高需要人工核实。这里先批量填入三十二米，再将单栋建筑改为五十二米。本例使用示例楼高，实际应用应逐栋核实，确认后再计算。

04 / 位置编辑 / 40.50–50.53 秒

拖动候选场站，坐标随位置同步变化。编辑后的地图可以独立保存，保留原始底图与可编辑组件，作为后续仿真的输入。

05 / 应用地图 / 50.53–59.57 秒

应用地图并计算，主界面的场站、航路和指标随输入更新。计算完成后，点击播放，检查新地图上的配送过程。

06 / 固定比较条件 / 59.57–66.60 秒

下面采用标准园区，保持地图、订单、机队及评价种子相同，两次运行仅切换错峰设置。

07 / 基线运行 / 66.60–82.93 秒

先关闭多机错峰起飞。参数变化后，旧结果进入待计算状态，需要重新计算才能播放和导出。算完点击播放，无人机、时间轴和订单数同步变化。本次综合风险布局，全程检测到五次间距不足。

08 / 定位事件 / 82.93–99.13 秒

拖动时间轴到两百二十五秒附近。约两百三十四秒，返回中的无人机接近配送悬停的无人机，出现红色预警。本段事件最小间距约零点七一米，低于二十米阈值，属于模型判定的间距不足。

09 / 修改调度 / 99.13–116.67 秒

现在开启错峰，重新计算。地图、订单和机队参数保持一致，只改变调度开关。错峰重新安排任务分配与运行时序。计算完成后，本次综合风险布局的全程间距不足由五次降为零，统计覆盖完整配送过程。

10 / 同刻复核 / 116.67–133.97 秒

将两种调度方案放在同一仿真时刻比较。左侧是基线，右侧是错峰。观察红色标记出现和消失的过程，以及两侧无人机位置的差异。错峰改变了任务分配与运行时序，在本次运行中避免了间距不足。

11 / 检查代价 / 133.97–150.47 秒

本次平均配送从一百零八点九一秒变为一百一十点零六秒，增加约一点一五秒，路径暴露也略有上升。两次均完成全部订单，准时率均为百分之百。风险与时效需要结合这组实验一起权衡。

12 / 切换布局 / 150.47–165.33 秒

保持错峰设置，先选距离优先，再切换综合风险。选中场站由三号加七号变为二号加六号，航路和指标同步更新。两种方案共用风险加权航路规划，区别在于场站评分目标。

13 / 图层与比较 / 165.33–177.40 秒

切换航路和人员暴露图层，观察航路与高暴露区域的位置关系。再打开方案对比页，在同一组订单下综合检查时效、暴露、间距不足和完成率。

14 / 导出结果 / 177.40–187.40 秒

点击导出结果，将结果数据、订单明细和对比图表保存到指定目录。在状态栏确认导出已经完成，随后打开文件核对。

15 / 核对文件 / 187.40–202.80 秒

使用外部只读查看器，核对导出文件中的评价种子、错峰开关和方案指标。再查看订单明细，任务、起飞和等待时间均有记录，可以追查具体订单，分析配送时间与调度等待的关系。

16 / 适用边界 / 202.80–212.17 秒

系统采用固定高度和理想运动模型，人员暴露为代理指标。实际应用前，需要用现场数据核实参数，再评价方案。

18 / 输出与复核 / 212.17–216.23 秒

导出结果数据、订单明细和图表，供后续复核与分析。
