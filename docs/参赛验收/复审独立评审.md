2. **文件来源：通过。** 独立重新计算两份源研究、manifest内7个源码及全部列举输出文件SHA256，均匹配。研究初5种子和追加20种子分列，未将其包装为新增真实地图或真实订单。
3. **指标重算：通过。** 从10800条新任务、导出路线顶点和场景高斯人员场独立计算路径几何距离与中点积分（5600次重复航路检查），再计算每单往返暴露、平均配送、最近秩P95、准时率、完成率、失败数和事件数。240种方案均与实际stats及CSV一致。200行逐种子差值、112行均值/样本SD/范围/优平劣按原始数值全部重算一致。未以团队“passed”字段替代此核验。
4. **运行重放：通过。** 对两地图新种子20261020和20261039的高峰组，共4组、12种方案重新调用实际模型；所有jobs和stats与新快照完全一致。其他新增组进行原始任务与指标全量核验，而非宣称全部再次排程。
5. **连续轨迹：通过，限既定模型。** 评委另行从job时刻、route点距和speed生成线性去程/返程及悬停段，不调用生产`airspace`或团队`verify_continuous_model`计算。10800任务生成1,121,851段运动，检查1,716,229个正时长重叠段对，最小距离20.0米，未发现低于阈值减1e-6米的持续片段。
6. **图形与最小依赖：通过已测范围。** 评委实际运行`python -X utf8 -S cases/verify_sites_gui.py`，通过真实Tk窗口测试：从主界面进入、1/3/8/20架真实机队、参数改动重算、六行正常高峰结果、回放/播放、两类导出、JSON重读、普通Excel模板、1000×680逻辑窗口按钮、取消和旧入口重算。此项使用团队提供的回归脚本实跑，不声称完成任意电脑、Python3.10或所有图片编辑器人工操作。

### 正时长事件与瞬时地空交接的判断

新增审计及证据明确存在33次同站“一个任务land_start恰等于另一个任务depart”的瞬时交接。例如正常场景20261015、距离优先、S3，287.279878秒。该瞬间前者由空中切为地面，后者由地面切为空中。

原`airspace.segment_violation`及既有测试已定义只计正时长共同空中区间，地面准备和降落服务排除；团队未修改生产定义。边界构造中零时长相邻区间不计事件，0.01秒正时长重叠被生产与独立审计同时检出。**按既有模型，这属于已披露的模型边界，不判为本轮引入的算法错误或通过降低标准规避缺陷。**

但当前模型不能证明同站连续物理起降安全，也不能支持“任何时刻都保持20米”“真实航空避碰已完成”。报告/答辩须保留此限制；若后续声称真实起降安全，则现有证据不足，应补充起降阶段占用和爬升下降建模，而不是沿用本次模型内通过结论。
