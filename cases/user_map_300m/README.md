# 用户提供的真实地图：300米案例

原始图片为用户提供的真实地图截图。用户说明：整图横向宽300米，楼高均不超过30米。地点名称、地图服务商和截图日期尚未提供。

`original.jpg`保留原始截图。`annotations.json`为人工近似描绘的像素轮廓与测试点位；`scene.json`为可直接导入程序的地图，内嵌原图。

16组可见轮廓分为22个矩形障碍块，U/L形分块处理。G12局部被定位标记遮挡，边界仍需核对；这些编号不是已核实的真实建筑清单。候选起飞点、配送点、订单和人群热点均为测试设置。

楼高统一使用30米上界做保守情景，`height_confirmed`仅表示该试跑输入已明确，`height_source`和`height_is_upper_bound`说明它不是逐栋实测值。30米巡航测试绕楼；45米巡航在当前模型下可越过所有这些建筑。平面间距3米、垂直间距5米均为模型参数。

运行 `python cases/run_user_map_case.py` 重建场景并比较3/5/8架机、30/45米高度、正常/高峰需求和三种选址方案。结果保存在 `results/user_map_300m/测试报告.md`。

安装可选研究图表依赖后，运行 `python cases/plot_user_map_case.py` 可生成地图与容量对照图。统计误差线为样本标准差，不是置信区间。

完整研究快照以标准gzip压缩保存在 `results/user_map_300m/studies/`，程序直接读取以便携带。逐次运行的JSON、CSV、SVG展开目录仍保存在本机，可用复现命令重新生成。

双击根目录的“启动真实地图测试.cmd”，或运行 `python cases/run_user_map_case.py --gui`，可打开已计算的5架机保守绕楼案例。工作台仍支持设置1—20架无人机。

当前案例定位为“真实空间截图下的参数化仿真试跑”。正式应用或参赛应补充位置、来源日期、无遮挡轮廓、楼高依据和真实点位与需求依据。
